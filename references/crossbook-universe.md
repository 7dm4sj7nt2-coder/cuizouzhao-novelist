# 崔氏统一宇宙（跨书互文体系）

> 三本书共享同一底层世界观，构成「崔氏宇宙」。跨书互文是崔走召的招牌技法之一。

## 共享道具
| 道具 | 出没 | 说明 |
|---|---|---|
| 七宝白玉轮 | 三书 | 逆天改命邪阵：黄巢剑/阴阳眼/无本魂/太岁皮/鬼眼泪/百人怨（陈抟所创） |
| 二十四周通明灯 | 阴阳+鸟人 | 蓝火查妖气/回魂路指路 |
| 讥笑槐 | 阴阳+三途 | 阴间树种，手掌叶，负面情感凝结 |
| 铜钱剑 | 阴阳+鸟人 | 一百二十枚铜钱/艾蒿杆包柄/至阳之物 |
| 黄巢剑 | 阴阳+鸟人 | 地府实体=阳间虚体；铜锈=剑鞘 |
| 太岁皮/白帚妖星 | 三书 | 妖星现世/太岁皮=七宝材料 |

## 共享角色
| 角色 | 出场 | 说明 |
|---|---|---|
| 崔作非 | 阴阳（主角）→鸟人（崔先生） | 阴阳先生主角在《鸟人》中是张是非的师父/雇主 |
| 九叔 | 阴阳→鸟人 | 崔先生师父=「小九」（劳动改造中） |
| 白无常谢必安 | 三书 | 吊死鬼霸主，贪财，一见发财帽 |
| 黄帽子神秘人 | 阴阳+鸟人 | 哄骗刘喜学道/扯断杜非玉黑绳（「游戏开始了」）——跨书最大幕后伏笔 |
| 易欣星/刘雨迪/刘喜 | 阴阳+鸟人 | 角色直接串场 |
| 陈图南=陈抟 | 三途+鸟人 | 三途最强弟子=瀛洲竹林仙 |

## 共享秘境
- 阴市（一步少半步多）：三书交界
- 瀛洲（桃花源/竹林仙/两界笔）：三途志+鸟人
- 三途村（地狱18层上空）：三途志
- 蛇洞山（燃西藏宝地）：鸟人

## 世界观共同底层
- 魔神统一法则（天地难全）：巨型存在=未孕育完整的魔神
- 灵魂体系：三生石下黄豆藤滋生灵魂；无本魂；迷蒙期；五弊三缺
- 正邪同源：三祖师（道/佛/巫）一脉分出正邪
- 情绪驱动超自然：负面情绪是力量燃料（妖卵/七死敛魂）

## 写作应用
- 彩蛋考古式互文：老读者跨书找线索（道具/角色/秘境复用），新读者不觉突兀（每次出现自带说明）。
- 跨书伏笔：黄帽子神秘人=跨书最大谜底；七宝白玉轮=三书共享核心道具。
