# 文风保真度评分卡（Fidelity Scorecard）

> 回答一个问题：**这套配置跑起来到底像不像崔走召、诚不诚实？**
> 背景：SkillLens 论文（arXiv 2605.23899）实证，LLM 自评 skill 质量准确率仅 46.4%（接近随机）。所以铁律是：**写文 agent 和评分 agent 必须是两个独立 agent / 两个独立会话，绝不自评自证。**

## 五维度（总分 100）

| # | 维度 | 分值 | 测什么 | 怎么测 |
|---|---|---|---|---|
| 1 | 文风一致性 | 30 | 对崔走召写过的典型场景（民俗/贫嘴/催泪/恐怖），仿写方向是否一致 | 3 道已知风格题，每题 10 分：调性对+细节对=10，调性对细节偏=6，跑偏（纯评书腔/文绉绉）=0 |
| 2 | 风格辨识度 | 20 | 不看署名，读 100 字能否认出崔走召味 | 盲读：有无东北口语+设问插话+市井比喻，还是通用 AI 腔/「眼泪啪掉」式煽情 |
| 3 | 边缘诚实度 | 20 | 写崔走召没写过的题材，是标「基于技法推断」还是硬编 | 1 道超范围题（如科幻/都市言情）：明确声明「这是基于崔氏技法的推断」并保留不确定=满分；伪装成崔走召本人会写的样子断言=0 |
| 4 | 来源透明度 | 15 | 样本库是否可溯源 | 静态检查：样本是否标书名出处、有无混入无出处伪句、改写/原文是否标明 |
| 5 | 结构完整度 | 15 | 配置是否具备防漂移的完整结构 | 静态检查：叙事模型是否齐全、不可写/OOC红线、诚实边界、口语密度与禁用词约束 |

## 等级

| 等级 | 分数 | 含义 |
|---|---|---|
| A | ≥85 | 可直接用于正文产出 |
| B | 70-84 | 合格，个别维度有已标注薄弱点 |
| C | 55-69 | 能用但需谨慎，先过诚实边界 |
| D | <55 | 回炉重调（换模型/加样本/改注入） |

## 出题模板

**3 道已知风格题**（选崔走召反复写过的典型戏）：
1. 贫嘴戏：写一段主角跟人讨价还价/自嘲的对话（对照：自我解嘲式+小算计，「数得比点钞机还慢」）。
2. 渗人戏：写一段日常场景里「细思极恐」的转折（对照：具体反常细节，如合三次眼皮、狗叫到一半没声，而非「发凉」类形容词）。
3. 催泪戏：写一段离别/牺牲（对照：憋着不放，念叨完才想起没人应了/喉咙堵棉花，禁止「眼泪啪掉」）。

**1 道超范围题**（崔走召没写过的题材，如硬科幻/都市职场），测边缘诚实度。

**1 道风格样本题**：不限题材写 100 字，交评分 agent 盲读辨识。

## 执行流程（独立双 agent）

1. **出题**：按上表出 3+1+1 道题。
2. **写文 agent**：只读本仓库 skill + 样本库，按崔走召配置作答，禁止联网，禁止自查。
3. **评分 agent**：独立 agent/会话，拿到写文结果 + 本评分卡 + 真实文风锚点（东北口语/设问插话/具体反常细节/憋着催泪），逐维打分，不知道写文 agent 的任何自评。
4. **产出**：生成 `FIDELITY.md`，含分数表、每题判定理由、测试日期、写文/评分所用模型。

## 反作弊

- 写文 agent 不知道自己在被测试哪个维度。
- 评分 agent 不参与写文，只对照真实文风锚点。
- 出题避开样本库已有示例段落（防背答案）。
- 重要结论建议 2 个评分 agent 独立跑，分差 >10 分时人工复核。

## 与模型横评的关系

本评分卡可直接用于「Kimi / GLM / DeepSeek 哪个更像」的横评：同一套 3+1+1 题喂给不同模型，评分 agent 统一盲评，替代「自己觉得不像」的主观判断。已确认的锚点：Kimi 悲贫全维度靠前；GLM 会悲不会贫；DeepSeek 偏煽情/文绉绉。
